# 知数 数学建模学习 App

0.1.0 本地预览版。沿用英语学习 App 的学习台、独立练习、学习记录与备份模式，面向大一零基础的数学建模学习。

包含完整 Day 2 课程、30天路线、逐项自动保存的草稿、不可覆盖的待批改作答、用户记录的老师反馈、TXT 导出、课程 JSON 导入、完整备份合并恢复，以及离线 Web App。没有后台、账号、AI接口或自动判分。只有记录老师实际确认的反馈后，才计为确认学习日。

Day 2 完整课程包括变量、参数、单位与 N/s/H/m 符号；50人示范；96人练习及N增长至120人的练习。练习答案未收入源代码。第3至30天为课程路线，可逐日导入完整课程包，不假装已完成全部课程。所有案例数据为虚构教学数据。内容基于用户提供的30天轻量备赛指南与指定的 Day 2 课程；不附原指南、原论文或比赛资料。

## 运行和预览

需要 Node.js 24+，在此目录安装 package.json 所列依赖，然后运行：

```sh
npm install
npm run dev
```

本机开发预览端口 5186。生产构建与离线预览：

```sh
npm test
npm run build
npm run preview
```

生产预览端口4186，首次缓存就绪后可断网重开。dist/知数-数学建模App-预览.html 可直接双击打开，不依赖服务器，但文件模式不支持安装为PWA，存储能力取决于浏览器。原生Android APK尚未生成。

当前开发机复用父目录现有依赖以避免重复安装；交付源码不携带父项目的依赖、数据库、签名文件或Git历史。新机器按此目录的package.json安装。本项目中的 private:true 用于禁止误发布为npm包，与GitHub仓库是否公开无关。

## 结构

- src/app：页面组装、导航与草稿生命周期。
- src/features：学习台、课程、课堂、记录和个人页。
- src/domain：课程、状态推导与导入格式检查。
- src/data：独立的 IndexedDB 数据库及原子写入。
- src/platform：文件下载与导入读取。

数据库稳定名称为 math-pocket-v1，与英语App完全独立。草稿、原始作答和反馈分别存储；反馈不改写历史答案。保存成功仅在IndexedDB写入成功后显示。导入先检查格式并预览，确认后在一个事务中合并；同名草稿保留本机版本，历史ID内容冲突则整次回滚。完整备份不等于云同步；恢复前仍建议另存本机备份。

## 公开源码与个人数据

公开（Public）仓库只包含源代码、原创课程与格式说明，排除个人作答、反馈、备份、密钥、原资料和构建缓存。仓库公开不等于App已部署或APK已构建。数学App的应用标识、学习库和签名与英语App分开维护。
